投影モード 操作マニュアル

セミナー当日に、コエミルを会場のスクリーン（サブスクリーン）に映して運用するための手順です。投影用パソコンを操作するスタッフ向けです。

1前日までの準備

設定（config.json）を確認する

設定はGitHubの config.json で行います。次の項目がその回のセミナーに合っているか確認してください。

eventTitle講演タイトル。投影画面の上部に表示されます。
csvUrl質問が集まるスプレッドシートの公開CSVのURL（/pub?output=csv の形）。
formUrl質問フォームの回答用URL。質問が0件のときに出るQRコードに使います。
availableFrom / availableUntil公開期間。当日が期間内に入っているか確認します。期間外だと「公開前です」「公開期間は終了しました」と表示されます。
hideDoneQuestions / excludeDoneFromCloud「取り上げ済み」にした質問を、一覧から隠す／ワードクラウドの集計から外すときに true にします（通常はどちらも false）。
refreshIntervalMs自動更新の間隔。本番は 30000（30秒）以上がおすすめです。
showPreQuestionsfalse にしておくと、講演中は事前質問を隠しておけます。

配布物を用意する

コエミルの画面の「フォーム素材づくり」から、QRコード案内のスライドと紙の質問用紙（A4）を作れます。紙の質問用紙は、スマホを使わない方向けに会場で配ります。

リハーサルをする

本番で使うパソコン・ブラウザ（Google Chrome をおすすめします）で、下の「2. 当日：投影を始める」を一度通しておきます。

リハーサルのあと、右上（投影中は右下）のボタンが「事前質問：非表示中」に戻っているか必ず確認してください。「表示中」のままにすると、当日もそのまま始まります。
また、リハーサルで「取り上げ済み」にした質問があれば、編集画面右上の 取り上げ済み ○件を解除 を押して、印を全部外してください。

2当日：投影を始める

  1. 投影用パソコンで Chrome を開き、https://koemiru.228.jp を開きます。
  2. 最新の状態にするため、強制再読み込みをします（Mac：⌘＋Shift＋R、Windows：Ctrl＋Shift＋R）。
  3. 画面上部に講演タイトルが出ていること、「自動更新」にチェックが入っていることを確認します。
  4. 右上のボタンが 事前質問：非表示中 になっていることを確認します。
  5. Chrome のウィンドウを、会場のスクリーン（サブスクリーン）側の画面に移動します。
  6. 右上の 投影モードで表示 を押します。画面いっぱいの表示（全画面）に切り替わります。
開演前から映しておけます。質問がまだ1件もないあいだは、「スマホで読み取って質問を送信」とQRコードが大きく表示されます。最初の質問が届くと、自動でワードクラウドに切り替わります。

3画面の見方

上部のバー左に講演タイトル、右に質問の件数（「質問 ○件」）。
上部バー右の小さな表示自動更新の状態です。● 緑「最終確認 14:05」：正常に確認できています。● 黄「更新が止まっています」：しばらく確認できていません。● 赤「更新できません」「自動更新オフ」：データを読めない、または自動更新が止まっています。黄や赤のときは「困ったとき」を見てください。
ワードクラウド質問によく出てくる言葉ほど大きく表示されます。色はカテゴリ（例：地方空港・釧路、貨物・物流など）ごとに分かれます。
人名は表示しません。「山﨑さん」「田中様」「〇〇氏」のような人の名前は、ワードクラウドに出ません（質問文そのものには残ります）。
光っている言葉新しく届いた質問に含まれる言葉です。約1分光ってから、ゆっくり消えます（その前に新しい質問が届けば、そちらの言葉に光が移ります）。
右下の2つのボタン事前質問：非表示中／表示中 と 編集画面に戻る。投影中は目立たないよう薄く表示され、マウスを近づけるとはっきり出ます。

4講演中

  • 操作は不要です。30秒ごとに新しい質問を確認し、届いていればワードクラウドが自動で更新されます。
  • 会場・Zoom から届いた質問だけが表示されます。事前質問は、まだ件数にも入りません。
  • 紙の質問用紙で受け取った質問は、スタッフがGoogleフォームに入力すると反映されます。
フォームから送ってから画面に出るまで、数分かかることがあります（Google側の反映待ち）。すぐに出なくても故障ではありません。

5講師との対談：事前質問を表示する

  1. 対談に入ったら、右下の 事前質問：非表示中 を押します。
  2. ボタンが 事前質問：表示中（黄色）に変わり、事前質問がワードクラウドに加わります。事前質問の言葉が光り、件数も増えます。
  3. もう一度押すと、事前質問をまた隠せます。
この切り替えはブラウザに記憶されます。途中でページを開き直しても、元に戻りません。

6質問を取り上げる（1件だけ大きく表示）

  1. ワードクラウドの言葉をクリックすると、その言葉を含む質問の一覧が出ます。
  2. 一覧の中から取り上げたい質問をクリックすると、その質問だけが大きく表示されます。質問者の所属・お名前が入力されていれば、質問のあとに（　）で表示されます。
  3. 1件表示にした質問は、自動で「取り上げ済み」になります。一覧に戻ると、その質問に ✓ が付いて薄くなり、いちばん下に回ります（隠す設定のときは一覧から消えます）。その言葉の質問がすべて取り上げ済みになると、ワードクラウドの言葉も薄い色になります。間違えて開いたときは、上の ✓ 取り上げ済み（取り消す） を押すと外せます。
  4. 左上の ← 一覧に戻る で一覧に戻ります。
  5. 表示の外側（暗くなっている部分）をクリックすると閉じて、ワードクラウドに戻ります。
投影中は Esc キーを押さないでください。全画面表示が解除され、投影モードも終わってしまいます。戻るときは、マウスで「← 一覧に戻る」や外側をクリックしてください。もし解除されたら、もう一度「投影モードで表示」を押せば元に戻ります。
1件を大きく表示している間に新しい質問が届いても、表示中の質問はそのまま変わりません。
一覧は、まだ取り上げていない質問が新しい順に上から並びます。同じ文の質問は1件にまとめて表示します。
「取り上げ済み」の印は、操作しているパソコンのブラウザに保存されます（ページを開き直しても残ります。ほかのパソコンには引き継がれないので、当日は1台で操作してください）。

7終わり方と後片付け

  1. 右下の 編集画面に戻る を押すと、投影モードが終わります。
  2. 画面上部の「開催レポートを作成 →」を押すと、質問の総数・参加方法別の件数・ワードクラウド・よく出た言葉・カテゴリ別の件数・全質問の一覧を1つにまとめたレポートが出ます。「印刷・PDFに保存」で社内報告や講師への資料に使えます（事前質問を非表示にしていても、レポートには全件入ります）。
  3. セミナー後は、Googleスプレッドシートの「ウェブに公開」を停止してください。質問データが外から見られなくなります。
  4. 必要に応じて、config.json の availableUntil（公開終了日時）を設定します。期間を過ぎると、コエミルのページは「公開期間は終了しました」と表示されます。

8困ったとき

質問を送ったのに画面に出ないGoogle側の反映に数分かかります。少し待ってください。長く出ない場合は、スプレッドシートに質問が入っているか確認します。
件数が一瞬減って、また戻ったGoogle側が更新直後に古いデータを返すことがあるためです。数分で落ち着きます。
画面が古い・変更が反映されていない強制再読み込み（Mac：⌘＋Shift＋R）をしてください。
上部バー右の表示が黄色・赤になった「自動更新オフ」なら、編集画面に戻って「自動更新」にチェックを入れます。「更新できません」「更新が止まっています」なら、ネット接続を確認し、強制再読み込みをしてから投影モードに入り直します。
全画面が解除されたもう一度「投影モードで表示」を押します。
「公開前です」「公開期間は終了しました」と出るconfig.json の availableFrom / availableUntil と、パソコンの時計を確認します。
質問が0件なのにQRコードが出ないconfig.json の formUrl が入っているか確認します。
事前質問がはじめから表示されている右下のボタンを押して「事前質問：非表示中」にします。
人の名前がワードクラウドに出てしまった辞書が知らない名前で「さん」「様」などが付いていないと、出ることがあります。config.json の excludeWords にその言葉を追加すると、出なくなります。
Safari でうまく動かないGoogle Chrome を使ってください。
