# コエミル（セミナーQ&A集計ツール）

Googleフォームで集めた質問をスプレッドシートから読み込み、頻出キーワードのワードクラウドと、
クリックした単語・カテゴリで質問をグループ表示する単一HTMLツールです。サーバー不要、GitHub Pagesでそのまま公開できます。

## 1. スプレッドシートを公開する（自動更新を使う場合）

1. 回答が入るGoogleスプレッドシートを開く
2. `ファイル` → `共有` → `ウェブに公開`
3. 公開する対象を「該当のシート（回答タブ）」、形式を **カンマ区切りの値（.csv）** に設定
4. 発行されたURL（`https://docs.google.com/spreadsheets/d/e/.../pub?output=csv`）を控える

非公開のまま使いたい場合は、この手順は不要です。ツール側の「CSVファイルをアップロード」から
手動でCSVを読み込めます（この場合、自動更新はできません）。

## 2. GitHubリポジトリを作成してPagesを有効化する

1. GitHubで新しいリポジトリを作成する（Public推奨。Privateの場合はGitHub Pagesが有料プラン限定になります）
2. このフォルダ内の `index.html` をリポジトリのルートにアップロードする
3. `Settings` → `Pages` を開く
4. `Source` を `Deploy from a branch`、ブランチを `main`（または既定のブランチ）、フォルダを `/root` に設定して保存
5. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` でアクセスできるようになる

## 3. config.json で自動読み込みを設定する（推奨）

`index.html` と同じ場所に `config.json` を置いておくと、ページを開くだけで
CSV読み込み → 列指定 → 集計 → 自動更新設定までを自動で行います。
セミナー当日は画面を開くだけで済むので、投影モードでの運用に向いています。

```json
{
  "csvUrl": "https://docs.google.com/spreadsheets/d/e/XXXXXXXX/pub?gid=0&single=true&output=csv",
  "questionColumn": "質問内容",
  "categoryColumn": "カテゴリ",
  "excludeWords": "質問, 教えて, ください",
  "autoRefresh": true,
  "refreshIntervalMs": 60000
}
```

| 項目 | 内容 |
|---|---|
| `csvUrl` | 公開CSVのURL（`pub?...&output=csv` 形式） |
| `lockDataSource` | `true` にすると、画面のURL入力・読み込みボタン・CSVアップロードを隠し、`csvUrl` だけをデータソースとして使う（省略時は `false`）。画面上の誤操作を防ぐための機能で、`config.json` は公開ページから誰でも読めるため、アクセス制限やセキュリティ対策ではない。`true` なのに `csvUrl` が無い、または読み込めない場合は、画面にその旨のエラーが表示される |
| `questionColumn` | 質問文が入っている列名（スプレッドシートのヘッダーと完全一致させる） |
| `categoryColumn` | カテゴリ列名。使わない場合は `""` にする |
| `excludeWords` | 除外語をカンマ区切りで指定 |
| `morphology` | `true` にすると形態素解析（辞書約18MBをCDNから読み込み）を使う。省略時・`false` は簡易抽出のみで、辞書は読み込まない |
| `eventTitle` | セミナー名。画面上部と、投影モード上部のバーに表示する（省略可） |
| `speaker` | 登壇者名。通常画面のセミナー名の隣と、form-kit.html の画像に使う。投影モードには表示しない（省略可） |
| `formUrl` | 質問受付用Googleフォームの回答用URL（`https://forms.gle/...` など。編集用の `/edit` のURLは不可）。form-kit.html のQRコードに使う（省略可） |
| `autoRefresh` | `true` にすると自動更新が有効になる。更新間隔ごとにスプレッドシートを確認し、質問の追加・修正・削除があったときだけ画面を更新する（変化がなければ画面は作り直さない） |
| `refreshIntervalMs` | 自動更新の間隔（ミリ秒）。5000 / 15000（テスト用）/ 30000 / 60000 / 300000 のいずれかに対応 |

**運用方法**: セミナーやスプレッドシートの構成が変わるたびに、`config.json` の値を書き換えて
GitHub上でコミットしてください（GitHub Pagesはブラウザから書き込みできないため、設定変更は
このファイルの手動コミットで反映する運用になります）。

`config.json` が存在しない場合は、これまで通り画面上でURL入力・列指定を手動で行う形にフォールバックします。

## 4. 使い方（config.json を使わない場合）

1. 公開したページを開き、CSVのURLを貼り付けて「読み込む」
2. 「質問文の列」（必須）と「カテゴリの列」（任意）を選択
3. 「集計する」を押すとワードクラウドとカテゴリ集計が表示される
4. ワードクラウド内の単語、またはカテゴリをクリックすると、該当する質問一覧が下に表示される
5. Zoom・会場のハイブリッド開催中は「自動更新」をオンにしておくと、一定間隔で自動的に再集計される

## 投影モードの表示

- 上部バーに、セミナー名を太字で大きく、質問の総数とあわせて表示します（`eventTitle` を設定した場合）。登壇者名は表示しません。
- 自動更新で質問が増えると、件数が増えた単語（最大12語）がぽんと大きくなり、黄色い囲みで光ります。光は次の更新まで続き、次の更新で新たに増えた単語に切り替わります（増えた単語がない更新では消えます）。最初の表示では光りません。OSの「視差効果を減らす」設定がオンの場合は、拡大と点滅を省き、囲みだけを表示します。

## Googleフォームの素材づくり（form-kit.html）

`https://koemiru.228.jp/form-kit.html` を開くと、質問受付用Googleフォームの素材を作れます。講演タイトル・講師は `config.json` から自動で入ります。

- **ヘッダー画像（1600×400）**: フォームのテーマ →「ヘッダー」→「画像を選択」でアップロードする。
- **QRコード案内（1920×1080）**: フォームのURL（「送信」→リンクのアイコンで出る回答用URL）を入れると作れる。会場のスクリーンやZoomの画面共有で使う。QRコードだけの画像（印刷用）も保存できる。
- **紙の質問用紙（A4）**: スマホを使わない方向けの記入用紙。A4に2枚分（切り取り線付き）または1枚分を選んで印刷する。フォームのURLを入れると「スマホからも送れます」のQRコードが付く。カテゴリのチェック欄も付けられる（選択肢はフォームの「カテゴリ」と同じものを入れる）。回収した用紙はスタッフがフォームに入力する。
- **テーマ色**: カスタム色 `#1F7A4D`（コエミルの濃い緑）。背景はいちばん薄い色。

## 注意点

- データはすべてブラウザ内で処理され、外部サーバーには送信されません。
- キーワード抽出は、初期設定では漢字・カタカナ・英数字の連続を拾う簡易抽出です。`config.json` で `"morphology": true` にすると、形態素解析（Kuromoji.js）で名詞だけを取り出し、「駐車＋場」「新＋千歳空港」のような部品は1語にまとめます。
  - 辞書（約18MB）はCDN（jsDelivr）から読み込みます。初回のみ時間がかかり、2回目以降はブラウザのキャッシュが使われます。会場のネットワークで事前に一度開いておくことを推奨します。
  - 辞書は待たずに、まず漢字・カタカナ・英数字の連続を拾う簡易抽出で表示し、辞書の読み込みが終わった時点で自動的に切り替わります（辞書の処理は別スレッドで行うため、読み込み中も画面は操作できます）。読み込めない場合は簡易抽出のままです。どちらで抽出したかは集計結果のメッセージに表示されます。
  - 「地方空港」は「地方」「空港」に分かれます。不要な語は `excludeWords`（または画面の除外欄）に追加してください。
- Googleスプレッドシート側の公開設定を解除すると、自動更新は失敗します。
